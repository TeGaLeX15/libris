# Libris

> Современная desktop-читалка книг с акцентом на удобство, производительность и красивый интерфейс.

## ✦ О проекте

**Libris** — приложение для чтения и управления электронной библиотекой.

Проект создаётся с нуля на **C# и Avalonia UI** с использованием **SukiUI**. Основной фокус — современный desktop-интерфейс, адаптивная компоновка, плавная работа и удобный процесс чтения.

## ✦ Возможности

### Реализовано

* 🖥️ базовая оболочка приложения
* 🧭 навигация между основными разделами
* 🎨 интеграция SukiUI
* 🌓 система тем
* 📚 библиотека книг
* 📥 импорт EPUB, FB2, PDF и TXT
* 🖼️ автоматическое получение обложек и метаданных
* 🔎 поиск по названию и автору
* ↕️ сортировка библиотеки
* 📐 адаптивная сетка книг
* 🖥️ поддержка разных размеров окон и разрешений
* 🪟 современный glass-интерфейс карточек книг

### В планах

* 📖 современный режим чтения
* 🔖 закладки и сохранение прогресса
* 📑 оглавление
* 🎨 настройка внешнего вида чтения
* 🗂️ коллекции
* 🌙 расширенная настройка светлой и тёмной тем
* 📚 дополнительные возможности управления библиотекой

Libris находится на ранней стадии разработки. Основная оболочка приложения и библиотека уже работают, а новые возможности добавляются поэтапно.
