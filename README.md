# Libris

> Современная desktop-читалка книг с акцентом на удобство, производительность и красивый интерфейс.

## ✦ О проекте

**Libris** — приложение для чтения и управления электронной библиотекой.

Проект создаётся с нуля на **C# и Avalonia UI** с использованием **SukiUI**. Основной фокус — современный desktop-интерфейс, плавная работа и удобный процесс чтения.

## ✦ Возможности

### Реализовано

* 🖥️ базовая оболочка приложения
* 🧭 навигация между основными разделами
* 🎨 интеграция SukiUI
* 🌓 подготовленная система тем

### В планах

* 📚 библиотека книг
* 📖 современный режим чтения
* 🔖 закладки и сохранение прогресса
* 🔎 поиск по библиотеке
* 📑 оглавление
* 🎨 настройка внешнего вида чтения
* 🗂️ коллекции
* 🌙 светлая и тёмная темы
* 📄 поддержка EPUB, FB2, PDF и TXT

## ✦ Стек

* **C#**

* **Avalonia UI**
