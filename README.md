# Libris

> Современная desktop-читалка книг с акцентом на удобство, производительность и красивый интерфейс.

## ✦ О проекте

**Libris** — приложение для чтения и управления электронной библиотекой.

Проект создаётся с нуля на **C#**, **Avalonia UI** и **SukiUI**. Основной фокус — современный desktop-интерфейс, адаптивная компоновка, плавная работа и удобный процесс чтения.

## ✦ Архитектура

Libris использует архитектуру **MVVM**.

Основные компоненты проекта разделены по ответственности:

- **Views** — пользовательский интерфейс на Avalonia XAML
- **ViewModels** — состояние и логика представлений
- **Services** — работа с данными, настройками и файлами
- **Models** — модели данных приложения
- **Converters** — преобразование данных для UI

Такое разделение позволяет независимо развивать интерфейс, бизнес-логику и работу с данными.
